# Dalassul Gestoria
Sistema online para gestão de projetos e processos de negócios e licitações

## Configuração do Ambiente

1. Clone o repositório.
2. Navegue até o diretório `backend` e instale as dependências:
    ```bash
    pip install -r requirements.txt
    ```
3. Navegue até o diretório `frontend` e instale as dependências:
    ```bash
    npm install
    ```
4. Inicie o servidor backend:
    ```bash
    python app.py
    ```
5. Abra o arquivo `frontend/index.html` no navegador.

## Estrutura do Projeto

- `backend/`: Contém o código do servidor backend.
- `frontend/`: Contém o código do frontend.
